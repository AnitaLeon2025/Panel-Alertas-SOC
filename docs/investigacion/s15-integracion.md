# S15 · Integración y publicación

## ¿Qué es GitHub Pages y qué archivos se publican?
GitHub Pages publica un sitio web gratis desde un repositorio de GitHub. Solo sirve archivos estáticos: HTML, CSS, JavaScript e imágenes, sin código de servidor. Nuestro proyecto funciona así porque todo se ejecuta en el navegador.

## ¿Qué límites y riesgos tiene localStorage?
localStorage no está cifrado, así que cualquiera que use el navegador puede ver y cambiar los datos, y un script de la misma página también podría leerlos. Solo guarda texto, tiene un límite de unos 5 MB y los datos viven en un solo navegador, donde se pierden si se limpian. Por eso no guarda contraseñas ni datos reales.

## ¿Cómo se diseña un caso de prueba manual?
Un caso de prueba manual es una prueba que una persona hace a mano. Se diseña con lo que se prueba, los pasos, el resultado esperado y el resultado obtenido.

## Aplicación en el proyecto
Publicamos el sitio en GitHub Pages y documentamos 15 pruebas manuales en docs/pruebas.md, con sus pasos y resultados.
