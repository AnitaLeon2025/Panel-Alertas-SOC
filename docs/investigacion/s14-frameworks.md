# S14 · Frameworks Front End

## ¿Qué problema resuelve un framework y qué es un componente?
Un framework resuelve el problema de organizar y actualizar la interfaz a mano cada vez que cambian los datos. Ofrece una estructura ya hecha para no repetir código. Un componente es una pieza de la interfaz, con su estructura y su lógica, que se escribe una sola vez y se reutiliza.

## ¿Qué partes de tu proyecto serían componentes reutilizables?
La tarjeta de alerta, que ya se usa en el Panel y en Alertas, el contador, el menú de navegación, el formulario, el cuadro de cierre y la barra de proporción.

## ¿En qué se diferencian React y Vue, en una frase cada uno?
React construye la interfaz con componentes escritos en JavaScript, usando JSX, que mezcla código y etiquetas. Vue también usa componentes, pero su plantilla se parece más a HTML y suele ser más fácil de aprender.

## Aplicación en el proyecto
En nuestro proyecto ya aplicamos esa idea a mano: la función crearTarjeta genera todas las tarjetas, y reglas.js reúne las reglas de cierre que usan el formulario y el cuadro de cierre.
